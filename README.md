# 🧮 Python Calculator

A simple and beginner-friendly command-line calculator built with Python 🐍.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Exponentiation
- 🧮 Modulus
- ⚠️ Handles division by zero
- 🚫 Handles invalid operators

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python calculator.py
